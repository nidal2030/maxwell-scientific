# maxwell-scientific
Responsive multi-page website for Maxwell Scientific, built with semantic, Polyglot-compliant HTML5 and CSS3.

## Project Specifications
* **Required Pages:**
  * `index.html`
  * `astro.html`
  * `chem.html`
  * `elect.html`
  * `eng.html`
  * `physics.html`
* **Stylesheet:**
  * `maxwell.css`
  * Desktop layout scaling to mobile at `max-width: 768px`
* **Polyglot Syntax:** Lowercase element/attribute names, quoted attribute values, and self-closing void elements (e.g., `<meta ... />`, `<img ... />`, `<br />`, `<hr />`).

## Internal Testing
* **Local preview:** Open `index.html` directly in a browser or launch via VS Code Live Server.
* **Validation:** Verify all `.html` files and `maxwell.css` against W3C validators for HTML5/Polyglot well-formedness and CSS3 validity prior to merging Pull Requests.
